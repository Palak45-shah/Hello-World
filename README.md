## 🚀 How to Run

### 1. Clone the repo via SSH
```bash
git clone git@github.com:Palak45-shah/Hello-World.git
```

### 2. Go into the folder
```bash
cd python-hello-world
```

### 3. Run the program
```bash
python3 hello.py
```

### 4. Output
Hello, World!
